\begin{itemize}
\tightlist
\item
  Body-size-based allometric trophic network (ATN) (Brose et al., 2006)
  models predict interactions from consumer--resource size
  relationships.
\item
  However, body size is only one determinant of trophic interactions;
  other traits and ecological constraints may be important.
\item
  \textbf{Aim:} quantify how often body-size-based ATN models predict
  interactions absent from empirical metawebs, and test whether network
  structure can nevertheless be recovered.
\item
  Prediction: ATN models will generate a high proportion of forbidden
  interactions, even when their broad structural properties resemble
  those of empirical metawebs.
\end{itemize}

\subsection{Template metawebs}\label{template-metawebs}

\begin{itemize}
\tightlist
\item
  \textbf{Great Britain:} European metaweb (Maiorano et al., 2020);
  subsampled to mammal species checklist from the UK Mammal Society -
  this is because some of the links in the european metaweb are
  `forbidden' due to co-occurrence limitations but could be feasible if
  species are treated as co-occurring. So this would have inflated the
  number of perceived forbidden links in the ATN. For Canada it is less
  of a problem since it is not constrained by co-occurrence.
\item
  \textbf{Canada:} probabilistic metaweb from Strydom et al. (2022).
\item
  \textbf{Body sizes:} mammalian body-mass estimates from PanTHERIA
  (Jones et al., 2009).
\item
  Briefly describe species matching, taxonomic harmonisation and
  missing-data handling.
\end{itemize}

\subsection{ATN models and forbidden
interactions}\label{atn-models-and-forbidden-interactions}

\begin{itemize}
\tightlist
\item
  Generate probabilistic and binary ATN networks using body size,
  varying \((R_{\mathrm{opt}}), (\gamma)\) and, for binary networks, the
  interaction threshold.
\item
  For probabilistic metawebs, account for uncertainty by sampling
  interactions.
\item
  Define forbidden interactions as ATN links absent from the
  corresponding metaweb.
\item
  Quantify the percentage of ATN links that are forbidden across
  parameter combinations and simulation replicates.
\end{itemize}

\subsection{Network structure
comparison}\label{network-structure-comparison}

\begin{itemize}
\tightlist
\item
  Compare a small set of structural metrics between ATN networks and
  metawebs (e.g.~connectance, degree distributions and nestedness, where
  appropriate).
\item
  Assess whether similar structural properties can coexist with poor
  recovery of specific species-level interactions.
\end{itemize}

\subsection{Body-size models predict many forbidden
interactions}\label{body-size-models-predict-many-forbidden-interactions}

\begin{itemize}
\tightlist
\item
  Report the percentage of predicted ATN links absent from the metaweb.
\item
  Show sensitivity to \((R_{\mathrm{opt}}), (\gamma)\), and the binary
  interaction threshold.
\item
  Compare results between Great Britain and Canada.
\end{itemize}

\subsection{Similar structure does not imply correct
interactions}\label{similar-structure-does-not-imply-correct-interactions}

\begin{itemize}
\tightlist
\item
  Compare structural metrics between ATN networks and metawebs.
\item
  Highlight any cases where structural similarity coexists with low
  pairwise interaction agreement.
\end{itemize}

\section{Discussion}\label{discussion}

\begin{itemize}
\tightlist
\item
  Body-size-based ATN models can predict interactions that are
  unsupported by the reference metawebs.
\item
  Structural similarity, if observed, does not necessarily imply
  recovery of the correct species-level links.
\item
  Discuss the limitations of body size as a sole predictor and the
  potential importance of additional traits and ecological constraints.
\item
  Note that metaweb absence is not definitive proof that an interaction
  is biologically impossible; results measure disagreement with the
  reference interaction data.
\end{itemize}
